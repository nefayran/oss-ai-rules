# AI and agent rules in 30 open-source repositories

Snapshot taken 2026-10-02. Every permalink is pinned to the default-branch HEAD commit read that day. Markdown and RST files carry `?plain=1` so the line anchor opens on the source view. Quotes are verbatim. `…` marks a cut and ` / ` marks a line or list-item break. Markup (`#` headings, `<!-- -->`, `>`, list dashes, `- [ ]`, link brackets) is dropped. "Last changed" is the newest commit touching that path (commits API, `path=` filter, up to the pinned sha). That edit is not always to the AI text itself.

Kinds: DISCLOSE (must say AI was used) · HUMAN-TEXT (descriptions, comments or commit messages must be written by a person, or an agent may not write or submit them) · ASK-FIRST (issue, assignment, label or maintainer/reviewer approval before a PR) · NO-BULK (bans automated, bulk or queue-driven workflows) · ATTRIBUTION (trailers required, allowed or forbidden) · OTHER (anything else AI-specific; described in brackets). "(soft)" marks a recommendation, not a requirement.

Name changes: `facebook/react` now resolves to `react/react`, and `strands-agents/sdk-python` resolves to `strands-agents/harness-sdk` (the API redirects both).
